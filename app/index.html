            📋 OpenSpec + TDD Cheat Sheet

            Use these commands in Claude Code to manage your feature workflow:

            🚀 /opsx-explore — Start here!
            Describe in plain language what you want and why
            /opsx-explore I don't want to lose what I typed in when I hit refresh
            /opsx-propose <name>
            Create a new change with proposal.md (the WHY)
            /opsx-propose delete-guest
            /opsx-design <name>
            Add design.md with technical approach (the HOW)
            /opsx-design delete-guest
            /opsx-tasks <name>
            Define acceptance criteria and test cases (the WHAT)
            /opsx-tasks delete-guest
            /opsx-derive <name>
            Copy tests from tasks.md to test files → RED
            /opsx-derive delete-guest
            /opsx-implement <name>
            Write code to make tests pass → GREEN
            /opsx-implement delete-guest
            /opsx-archive <name>
            Move completed change to archive
            /opsx-archive delete-guest
            /opsx-status
            Check progress across all changes
            /opsx-status
            💡 TDD Workflow
            ❌ RED → Write tests first (they fail)
            ✅ GREEN → Implement to make tests pass
            ♻️ REFACTOR → Clean up, add edge cases
