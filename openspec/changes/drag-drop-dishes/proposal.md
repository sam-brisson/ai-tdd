# Drag & Drop Dish Recategorization

## Why
Users sometimes add a dish to the wrong category (e.g., putting "Stuffing" under Desserts instead of Sides). Currently there's no way to fix this without deleting and re-adding the dish. This is frustrating and wastes time.

## What Changes
Allow users to drag dishes between category sections (Main, Side, Dessert, Appetizer) to recategorize them.

## Success Criteria
- [ ] Can drag a dish from one category to another
- [ ] Dish appears in new category after drop
- [ ] Change persists after page refresh
