# Delete Guest

## Why
> "I want to be able to delete a guest if I added in error!"

Currently there's no way to remove a guest once added. If you mistype a name or add the wrong person, you're stuck with them on the list forever. Users need a way to fix mistakes.

## What Changes
Add a delete button to each guest in the list. Show a confirmation prompt before deleting to prevent accidental removals.

## Success Criteria
- [ ] Each guest has a visible delete option
- [ ] Clicking delete shows a confirmation ("Are you sure?")
- [ ] Confirming removes the guest from the list
- [ ] Canceling keeps the guest
- [ ] Guest count updates after deletion
- [ ] Deletion persists after page refresh
