# Data Persistence

## Why
Users lose all their guests and dishes when they refresh the page or accidentally close the browser. This is frustrating because they have to re-enter everything. A Thanksgiving dinner planner should remember your plans!

## What Changes
Save guest list and menu data to localStorage so it persists across page refreshes and browser sessions.

## Success Criteria
- [ ] Guest data persists after page refresh
- [ ] Dish data persists after page refresh
- [ ] Data survives browser close/reopen
