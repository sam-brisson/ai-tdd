# Data Persistence

## Why

When planning a Thanksgiving dinner, I add guests and dishes to the planner. But if I accidentally refresh the page or close my browser, **all my data disappears** and I have to start over.

This is frustrating because dinner planning happens over multiple sessions - I might add some guests now and come back later to add dishes.

## What Changes

Save guests and dishes to the browser's localStorage so they survive page refreshes and browser restarts.

## Success Criteria

- [ ] Data persists when I refresh the page
- [ ] Data persists when I close and reopen the browser
- [ ] Existing functionality (add guest, add dish) continues to work
